# Python Development Skill

For Python development tasks:

1. Inspect the relevant files first.
2. Do not overwrite complete files unnecessarily.
3. Make small, verifiable changes.
4. Run the program after making changes.
5. Run available tests.
6. If an error occurs, read the complete error message.
7. Fix the issue.
8. Run the program again.
9. Consider the task complete only after successful verification.
